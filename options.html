Cognitive Shield

Filtre local des suggestions YouTube avec clef-flash (Ollama).

Connexion au modèle

Indique l'URL de base de ton serveur Ollama (ex. http://localhost:11434) : l'extension ajoute /v1/systemone automatiquement. Un endpoint complet (http://localhost:11434/v1/systemone) est aussi accepté. Prérequis : ollama pull clef-flash (Ollama ≥ 0.35.1, ~11 Go). Si Ollama répond 403, l'extension retire automatiquement l'en-tête Origin ; tu peux aussi lancer OLLAMA_ORIGINS='chrome-extension://*' ollama serve.
