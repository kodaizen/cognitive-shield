Cognitive Shield

Filtre des suggestions YouTube avec un modèle de décision Clef (Cloudflare Workers AI), Ollama ou FastFlowLM en local.

Fournisseur du modèle

Cloudflare exécute le modèle sur son réseau (aucune installation, jeton API requis) ; Ollama et FastFlowLM l'exécutent en local sur ta machine. Les deux parlent le même protocole de décision (System One). Tous utilisent le même prompt et le même seuil ci-dessous.

Cloudflare Workers AI

Les requêtes sont envoyées à l'API REST Cloudflare Workers AI : POST https://api.cloudflare.com/client/v4/accounts/<account_id>/ai/run/<modele>. Récupère ton Account ID et crée un jeton API disposant de la permission Workers AI (tableau de bord Cloudflare → AI → Workers AI → « Use REST API »). Modèle par défaut : @cf/cloudflare/clef-flash (9B, rapide, ~0,04 $/M tokens d'entrée) ; utilise @cf/cloudflare/clef (27B) pour plus de précision sur les cas difficiles.

Ollama (local)

Indique l'URL de base de ton serveur Ollama (ex. http://localhost:11434) : l'extension ajoute /v1/systemone automatiquement. Un endpoint complet (http://localhost:11434/v1/systemone) est aussi accepté. Prérequis : ollama pull — clef-flash (Ollama ≥ 0.35.1, ~11 Go) ou un modèle de décision d3 (d3:2b ~3,1 Go, d3:4b ~5,6 Go, d3:9b ~10 Go, d3:27b ~29 Go ; Ollama ≥ 0.40.9, contexte 256K, texte et images). Plus d'infos : Bibliothèque Ollama d3. Si Ollama répond 403, l'extension retire automatiquement l'en-tête Origin ; tu peux aussi lancer OLLAMA_ORIGINS='chrome-extension://*' ollama serve.

FastFlowLM (local)

FastFlowLM sert un modèle de décision d3 sur le NPU AMD (non génératif : probabilités directes, très rapide). Lance le serveur avec flm serve --decision d3:lite (port par défaut 52625) ; l'extension ajoute /v1/systemone automatiquement. Un endpoint complet (http://localhost:52625/v1/systemone) est aussi accepté. Prérequis : flm pull d3:lite (~ 0,8 Go, Q4_K, max 32 768 tokens d'entrée, images acceptées, une décision courte ≈ 0,1 s). Modèles plus précis mais plus lents : d3:nano (~ 2 Go, 2B), d3:mini (~ 3,4 Go, 4B) et d3:turbo (~ 16,6 Go, 27B, vidéo supportée, 28 Go de RAM requis). Plus d'infos : Documentation FastFlowLM d3.
